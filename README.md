# Sheilyn Colina — Data Science & Quantitative Finance

Página estática del portafolio. Presenta proyectos enlazados con su alcance y estado real; no incluye testimonios ni métricas comerciales sin respaldo.

## Vista local

Abrir `index.html` en el navegador o ejecutar:

```bash
python -m http.server 8000
```

Visitar http://localhost:8000. La página es autocontenida y adaptable a móvil. La copia histórica `html_finalprojimages/index.html` muestra el mismo contenido para evitar dos perfiles contradictorios.
